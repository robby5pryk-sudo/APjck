# APjck - TikTok Live comments replied to by Ai
TikTok Live comments replied to by AI

How to use it?

First, enter your TikTok username. Then, generate an API key on the Google AI Studio website.
Once you have the API key, enter it into the `.env` tab of `APjck_Launcher.exe`. Finally, start a live stream on the TikTok account you entered earlier and click the "GO" button within the application.
